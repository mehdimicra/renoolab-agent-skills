# Security

Ne publiez jamais de clé, jeton, donnée client ou document de chantier sensible dans une issue.

Signalez confidentiellement tout problème de sécurité à `contact@renoolab.fr`. Indiquez le skill concerné, le scénario, l'impact et les étapes minimales de reproduction.

Les actions MCP d'écriture exigent une confirmation explicite de l'utilisateur. Les coordonnées ne doivent être collectées qu'au moment nécessaire et pour la finalité demandée.
